# Flashing Ratchet Simulation

Stochastic simulation of motor-protein transport, modelled as particle motion in a one-dimensional flashing ratchet potential.

The project explores the system through numerical stochastic simulations. The complete analysis, implementation and results are available in [`project2.ipynb`](project2.ipynb).
